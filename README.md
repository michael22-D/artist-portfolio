# Derrick Akuamoah — Artist Portfolio

A responsive static portfolio for Ghanaian abstract mixed-media artist Derrick
Akuamoah. Built with HTML, CSS, and vanilla JavaScript; no build tools or
backend are required.

## Pages

- `index.html` — landing page, featured artworks, artist introduction, and enquiry callout
- `portfolio.html` — artwork gallery with category filters
- `artwork.html` — artwork details selected with `?id=artwork-01` through `artwork-09`
- `about.html` — artist biography, philosophy, and process
- `cv.html` — education, exhibitions, professional experience, and recognition
- `contact.html` — validated enquiry form that opens a prepared email

## Project files

- `css/style.css` — shared layout, responsive styling, and page components
- `js/main.js` — artwork data, gallery rendering, navigation, and form validation
- `img/` — artist and artwork photographs, including the landing-page hero

## Run locally

Open `index.html` in a modern browser, or serve this folder with a static web
server. There is no build or installation step.

## Content and contact

- Artwork details are maintained in the `artworkData` collection in `js/main.js`.
- The contact form validates fields in the browser and opens the visitor's email
  application; it does not submit data to a server.
- Artwork enquiries use [d.akuamoah2018@gmail.com](mailto:d.akuamoah2018@gmail.com).
